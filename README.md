### 👨‍💻 About Me

I am an **Embedded Systems Engineer** passionate about microcontrollers, low-level architecture, and bare-metal firmware. My approach to learning is strictly hands-on: diving into silicon datasheets, analyzing hardware schematics, tracing bus signals, and debugging at the register level.

My primary mission is designing **reliable, power-efficient, and fail-safe IoT systems** that solve real-world problems—focusing on environmental telemetry, disaster mitigation, and distributed off-grid communication networks.

<details>
<summary><b>📡 Deep Dive: Flash Flood Disaster Warning Architecture (Click to expand)</b></summary>

<br/>

A distributed battery-operated node system deployed in remote riverbeds where cellular networks are unavailable. The sensing nodes read water level and flow metrics, packetize the telemetry, and transmit across long distances using **LoRa RF** modulation to alerting gateways.

```mermaid
flowchart LR
    A["🌊 Water Level / Flow Sensor"] --> B["⚡ STM32 Ultra-Low-Power MCU"]
    B -- "SPI + IRQ (DIO1)" --> C["📡 LoRa SX126x Transceiver"]
    C -. "Long-Range RF Link" .-> D["📶 LoRa Gateway Hub"]
    D --> E["🚨 Critical Alert (Siren / SMS / Cloud)"]
```

**Key Architectural Highlights:**
- Custom **SX126x** driver implemented in C over hardware SPI with BUSY-pin state machine and timeout management.
- Dynamic packet validation, CRC checks, and multi-hop relay forwarding.
- Deep sleep power cycling optimizing battery endurance for multi-year remote deployment.

</details>
